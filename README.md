## Learning Materials

The repository contains lessons and practical labs covering:

- **Colors:** Tailwind color utilities.
- **Spacing:** Margin, padding and spacing utilities.
- **Typography:** Text sizes, weights, alignment and related utilities.
- **Responsive Design:** Responsive breakpoints and screen sizes.
- **Positioning:** Position, inset and related utilities.
- **Hover States:** Interactive hover utilities.
- **Integrated Lab:** A practical environment combining multiple concepts.

## Technologies

- HTML5
- Tailwind CSS
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Select a lesson or lab from the available links.
4. Experiment with the examples and interactive controls.

An internet connection is required for lessons that load Tailwind CSS through its CDN.

## Project Structure

The repository contains standalone HTML files for individual lessons and practical labs, alongside the main `index.html` landing page.
